# Security policy

## Supported versions

Zorg.Imaging is in early development. Nothing has been released yet. After the first preview, only the latest published version gets security fixes.

## Reporting a vulnerability

Report it privately through the repository's **Security** tab, using **Report a vulnerability**. Don't open a public issue.

Please include the affected version, the input file that triggers it (or how to make one), and the impact you expect. Decoders take untrusted input, so a crash, a hang, unbounded memory or an unhandled exception type from a crafted file is a security bug.
